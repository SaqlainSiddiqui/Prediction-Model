Used Car Price Predictor

Estimate the market price of a used car using machine learning.

About This Project

This application uses a machine learning regression model to estimate the asking price of a used car based on its characteristics.

Dataset

8,817 cleaned used-car records.

Algorithm

Tuned Random Forest Regressor.

R² Score

0.6369

MAE

Approximately ₹2.15 lakh.
